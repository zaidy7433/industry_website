# 🏭 Industry Website

A modern **Industry Website** designed for an industrial/construction business. The website has a clean professional layout with smooth animations, service cards, project images, and a responsive design.

## 🌐 Live Website

https://zaidy7433.github.io/industry_website/

## ✨ Features

* 🏠 Attractive hero section
* 🏭 Industry business design
* 🔧 Services section
* 👷 About company section
* 🏗️ Projects/gallery section
* 📞 Contact section
* ✨ CSS animations and hover effects
* 📱 Responsive design using `@media`
* 🎨 Modern color theme

## 💻 Technologies Used

* HTML5
* CSS3
* CSS Animations
* CSS Media Queries
